# NOTICE spec (Tier 2)

An attribution file, created/maintained **only when** the license calls for it
(Apache-2.0) or one already exists.

## Visual budget: none, ever

**NOTICE is an official legal document. It gets ZERO visuals, zero banners, zero
badges, zero markers, and zero formatting beyond the verbatim attribution text.** No
`pd:viz` embed, no `pd:footer`, no `pd:badges`, no design-system styling — nothing.
The file is the project name, the copyright attribution line, and any obligated
third-party attributions, in plain text. **Any `pd:` marker or image in this file is a
hard quality-gate violation** (house-style → Quality gates 3 and 10).

## Rules

- **Create when:** the license is Apache-2.0, or a `NOTICE` already exists and needs
  reconciling.
- **Content:** the project name and the copyright attribution line
  (`Copyright © <year> <holder>`), plus any third-party attributions the project is
  obligated to carry forward. Keep it minimal and factual.
- **Holder** follows the identity guardrail (organisation/entity, not a personal git
  identity).
- **Don't invent third-party attributions.** Include only attributions that genuinely
  apply (e.g. bundled code that requires them). If unsure whether something must be
  attributed, leave a `<!-- TODO: confirm third-party attributions -->` rather than
  guessing.
- Keep the holder/year in sync with LICENSE and the footer.
